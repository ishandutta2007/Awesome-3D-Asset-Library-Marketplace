## Overview & Key Highlights

Finding high-quality 3D assets is essential for game engines (Unreal Engine, Unity, Godot, WebGL/Three.js), VFX pipelines (Blender, Maya, Cinema 4D), and architectural visualization (ArchViz).

- **Commercial SaaS Marketplaces:** Adobe Substance 3D, Quixel Megascans, Poliigon, TurboSquid, Sketchfab, CGTrader, KitBash3D, and ArtStation Marketplace offer millions of high-fidelity models, procedural materials, and scans.
- **Open-Source & Free CC0 Repositories:** Poly Haven, BlenderKit, and Icosa Gallery offer public-domain and open-license assets without paywalls.
- **Self-Hosted Marketplaces:** Projects like 3D RGB and 3Dēx allow studios and communities to host, distribute, or sell 3D content independently without marketplace commission fees.

## Open-Source 3D Asset Libraries & Repositories

Explore community-driven, public domain, and self-hostable open-source 3D solutions.

### Featured Open-Source Projects

- **[Poly Haven](https://polyhaven.com/)** [![GitHub Stars](https://img.shields.io/github/stars/polyhaven?style=social&color=white)](https://github.com/polyhaven)  
  **The CC0 public asset standard.** A curated public library of high-dynamic-range images (HDRIs up to 16K resolution), photorealistic PBR textures (up to 8K), and 3D models. All assets are **100% CC0 (Public Domain)**, meaning zero copyright restrictions and full freedom for commercial use without attribution. **No paywalls, no login requirements, no tracking.** Funded via Patreon and open-source corporate sponsorships.

- **[BlenderKit](https://github.com/BlenderKit)**  
  **Integrated in-viewport 3D asset library.** Seamlessly search, preview, and drag-and-drop 3D models, procedural materials, HDRIs, and geometry node setups directly inside the Blender 3D viewport. Built under GPL licenses, BlenderKit supports open creators via a community model alongside extended ecosystem tools for Godot, Maya, and Unreal Engine.

- **[Icosa Gallery](https://github.com/icosa-foundation/icosa-gallery)** [![GitHub Stars](https://img.shields.io/github/stars/icosa-foundation/icosa-gallery?style=social&color=white)](https://github.com/icosa-foundation/icosa-gallery/stargazers)  
  **The open-source successor to Google Poly.** Apache 2.0 licensed platform for hosting, displaying, and distributing interactive 3D content and virtual reality assets. Built by the Icosa Foundation (maintainers of Open Brush and Open Blocks) to provide modern WebGL viewers, format conversion (glTF/GLB/USDZ), and Blender/Godot integration endpoints.

- **[3D RGB (3DMeta-Shop)](https://github.com/iranpsc/3DMeta-Shop-Object-3D)**  
  **Self-hosted 3D digital marketplace engine.** A production-ready eCommerce web application for selling 3D models, avatars, textures, and digital renders. Built with **Laravel, Blade, and Tailwind CSS**, featuring user authentication, catalog search/filter, shopping cart, download permission management, and an administrative control panel.

- **[3Dēx](https://github.com/Schryzon/3Dex)**  
  **AI-assisted 3D asset marketplace & 3D print platform.** Modern multi-sided platform connecting digital creators, customers, and physical manufacturing providers. Built with **Next.js, Node.js, PostgreSQL, MinIO, and pgvector**, featuring real-time WebGL previews, AI-based vector search (MiniLM + pgvector), and automated moderation.

### Additional Open-Source Tools & Registries

- **[open-source-3D-assets](https://github.com/m3-org/open-source-3D-assets)** — JSON-indexed registry of 990+ CC0 3D models and GLB metaverse assets optimized for programmatic consumption and automated asset pipelines.
- **[os3a-gallery](https://github.com/m3-org/os3a-gallery)** — Lightweight Next.js and Three.js gallery web application for discovering and previewing freely available GLB format 3D assets.
- **[forge-asset-libraries](https://github.com/hyperfy-xyz/forge-asset-libraries)** — High-performance Rust library for AI agents and game engines generating, validating, texturing, and compiling 3D asset packages.

## 3D Asset Types & Formats Reference

When evaluating asset libraries, compatibility with modern 3D file formats is critical:

| Asset Format | Extension | Primary Use Case | Supported Engines & Software |
| :--- | :--- | :--- | :--- |
| **glTF / GLB** | `.gltf`, `.glb` | Standard runtime transmission format for WebGL, WebXR, and modern engines | Three.js, Babylon.js, Godot, Unreal Engine, Unity |
| **USD / USDZ** | `.usd`, `.usdz`, `.usda` | Universal Scene Description for VFX interchange and Apple AR Quick Look | Blender, Maya, Houdini, Omniverse, iOS AR |
| **FBX** | `.fbx` | Legacy industry standard for rigged characters and complex animations | Unreal Engine, Unity, Maya, 3ds Max, Blender |
| **OBJ + MTL** | `.obj`, `.mtl` | Universal static geometry mesh representation | Compatible with virtually all 3D modeling tools |
| **EXR / HDR** | `.exr`, `.hdr` | 32-bit floating point high dynamic range environment lighting maps | Blender, Unreal Engine, Unity, Arnold, V-Ray, Octane |
